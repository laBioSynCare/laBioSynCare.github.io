SSTIM vocabulary documentation is generated at deploy time

The SKOS concept schemes are documented by pyLODE (vocpub profile) in the Pages workflow, into the deployed artifact only — WIDOCO, which produces the OWL reference, is OWL-centric and does not cover them. Neither is committed (ADR 0023), so this placeholder stands in during local development and deployment overwrites it. 

npm run build
make vocab-docs VOCAB_DOCS_DIR=dist/ontology/docs/vocab
npm run preview -- --host 127.0.0.1 --port 4174

Published at labiosyncare.github.io/ontology/docs/vocab/. The vocabulary Turtle is served here as a static asset, and every concept is browsable in the knowledge browser.
