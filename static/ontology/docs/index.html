SSTIM reference documentation is generated at deploy time

You are seeing this placeholder because you are running BSC Lab from source. The OWL reference (WIDOCO) and the SKOS vocabulary reference (pyLODE) are built by the Pages workflow into the deployed artifact and are never committed (ADR 0023). This file exists so that the links to /ontology/docs/ in the entrance, the About page and the top-bar menu land somewhere explanatory instead of a 404 during development; deployment overwrites it with the real index.

To read the real documentation locally, build it into the ignored output tree:

npm run build
make ontology-docs DOCS_DIR=dist/ontology/docs
make vocab-docs VOCAB_DOCS_DIR=dist/ontology/docs/vocab
npm run preview -- --host 127.0.0.1 --port 4174

Both generators need the pinned toolchain — run them inside nix develop. Generate into dist/, which is gitignored, and not into static/, where the output would overwrite this tracked placeholder.

The Turtle sources themselves are served here as static assets and need no build: manifest.json lists every module, and the knowledge browser reads them directly. The published documentation is at labiosyncare.github.io/ontology/docs/.
