# SSTIM ontology — frozen snapshot 0.2.0

These files are a **byte-identical, immutable copy** of the SSTIM ontology as of
version `0.2.0`. They exist so that
`owl:versionIRI <https://w3id.org/sstim/0.2.0>` resolves to a frozen
artifact that can be cited without ambiguity, even after the top-level
`/ontology/*.ttl` files continue to evolve toward the next version.

- Source commit: `fd0af476fe6877e4e50dc0df542345dd46bc55ef`
- Generated by: `scripts/snapshot-ontology.mjs`
- **Erratum patch (2026-06-13):** `sstim-core.ttl` and `sstim-alignments.ttl`
  were hand-corrected after generation to fix external alignment IRIs that were
  wrong since 0.1.0 — every Wikidata QID (all resolved to unrelated entities),
  the `EvidenceClaim` parent (`iao:0000001` → `iao:0000030`), the obsolete OBI
  planned-process parent (added `cob:0000082`), a non-existent ORCID, and a dead
  repository link. No vocabulary terms or definitions changed. The other three
  modules remain byte-identical to the source commit.
- To cut a new version, bump `owl:versionInfo` / `owl:versionIRI` in
  `sstim-core.ttl` first, then snapshot the new number.

Files: `sstim-core.ttl`, `sstim-vocab.ttl`, `sstim-shapes.ttl`, `sstim-alignments.ttl`, `sstim-patch-studio.ttl`.
